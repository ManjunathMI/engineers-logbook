# Privacy & Data Processing Policy

This documentation site is a static, open-source technical portfolio hosted via GitHub Pages.

### 🔒 Absolute Local Privacy
* **No Telemetry data collection:** This website does not log, track, or harvest personal user characteristics, cookies, or analytical parameters.
* **Zero Cloud Caching:** All workflows, script queries, and setup notes provided across these playbooks run completely offline on your physical workstation machine. No API strings are transferred externally.

### 📊 Third-Party Tracking
We embed a basic hits-counter SVG badge provided via `scruid.com` directly inside our global footer template layout to estimate aggregate traffic visits. It tracks numerical increments anonymously without identifying user metrics.
